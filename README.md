# Chatalyst — source code (read-only)

Modern chat suite for Paper & Purpur: formats, channels, private messages, rules,
moderation and staff tools, titles, market, Discord integration and more.

This repository lets you **read** Chatalyst's source code: see how it works, audit what it
does on your server, or integrate with its public API before you buy.

> **This is not a buildable project.** Build files, tests, the licensing system and some
> security modules are intentionally left out. Official builds are only available from
> Chatalyst's store page.

## What you can do here

- Read the code and the documentation (`docs/`).
- Build integrations against the public API in `src/main/java/dev/chatalyst/api`.
- Report bugs or suggest features through the official support channels.

## What you can't do

Compile, redistribute, modify or reuse this code in other projects. See [LICENSE](LICENSE)
for the full terms.
