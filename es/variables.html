Referencia

Variables

Escribe un texto una vez y reutilízalo en cualquier formato o mensaje como {nombre}. Las variables con JavaScript añaden lógica sencilla.

Las variables son trozos de texto que escribes una vez y reutilizas en cualquier sitio como {nombre}. Guarda en una variable el nombre de tu servidor, el enlace de Discord o una etiqueta con estilo, úsala en tus formatos y mensajes, y cámbiala después en un solo sitio.

Las variables de texto funcionan desde el principio. Las de script (con js:) necesitan los scripts encendidos.

#Crear una variable

Las variables están en plugins/Chatalyst/integrations.yml. Este es el ejemplo de fábrica:

yaml
Variables:
  server_name: "<gradient:#240046:#9D4EDD:#E0AAFF>YourServer</gradient>"
  discord_link: "discord.gg/example"
  # Variables con SCRIPT (JavaScript). Empieza el valor con "js:". Recibes 'player'
  # (el jugador) y 'playerName'. Ejemplos:
  #   {vip_tag}  ->  enseña [VIP] solo si el jugador tiene el permiso.
  vip_tag: "js: player.hasPermission('chatalyst.vip') ? '<#D8B4FE>[VIP] ' : ''"
  #   {name_len} ->  la longitud del nombre del jugador.
  name_len: "js: player.getName().length()"

Cambia los valores o añade tus propias líneas con cualquier nombre. Ejecuta /cht reload.

#Usar una variable

Escribe el nombre entre llaves en cualquier sitio donde Chatalyst enseñe texto: formatos de chat, mensajes de entrada, anuncios y comandos personalizados. Por ejemplo, el comando /discord puede usar el enlace de la variable, así solo lo tienes en un sitio:

yaml
    Messages:
      - "<#5865F2>Nuestro Discord: <#FBF2FF><underlined>{discord_link}"

#Variables con script

Un valor que empieza por js: es una pequeña expresión de JavaScript. Puede enseñar un texto distinto a cada jugador, por ejemplo una etiqueta [VIP] solo para quien tenga un permiso.

Los scripts vienen apagados. Enciéndelos en el mismo archivo:

yaml
Scripting:
  Enabled: true

Dentro de un script tienes player (el jugador) y playerName (su nombre). Los scripts se ejecutan en un motor seguro que bloquea las clases peligrosas, y se compilan una vez y se guardan en caché.

Consejo

Haz los scripts cortos: se pueden ejecutar en cada mensaje. Para una etiqueta según un permiso, una parte del formato con Sender_Permission es más rápida y no necesita scripts. Mira Formatos de chat.

#Variables y placeholders

Las variables son texto tuyo. Los placeholders son valores que rellena Chatalyst, como {player_name} o {ping}. Los dos usan el mismo estilo {nombre}; los que vienen de serie están en Placeholders.
