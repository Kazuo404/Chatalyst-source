Activar extras

Chatalyst viene solo con el chat encendido. Usa /cht features para ver cada función opcional y activar las que quieras.

Chatalyst es ante todo un plugin de chat. Una instalación nueva enciende el chat y sus protecciones, y deja apagado todo lo demás. Así tu servidor solo ejecuta lo que de verdad usas, y nada pilla por sorpresa a tus jugadores.

Esta página explica cómo ver qué está encendido y cómo activar un extra en dos pasos.

#Ver qué está encendido

Ejecuta esto en el juego o en la consola:

text
/cht features

Enseña dos listas. On son las funciones que están funcionando. Off son las apagadas, cada una con el ajuste y el archivo exactos que hay que cambiar, por ejemplo Mail.Enabled: true (players.yml). Necesita chatalyst.admin.

#Activar un extra

  1. Abre el archivo que dice la lista, dentro de plugins/Chatalyst/.
  2. Busca el ajuste y cambia false por true. Por ejemplo, para encender el correo en players.yml:
yaml
Mail:
  Enabled: true
  1. Guarda y ejecuta /cht reload. Algunas funciones necesitan reiniciar el servidor; /cht features te lo avisa cuando es así.

Para apagarlo otra vez, vuelve a poner false y recarga.

Nota

Actualizar Chatalyst nunca cambia estos interruptores en un servidor ya instalado. Lo que encendiste sigue encendido y lo que dejaste apagado sigue apagado.
