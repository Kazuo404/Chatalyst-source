## Support Baseline

When opening a support ticket, include:

- Chatalyst version and server software.
- Java version.
- Startup log from the Chatalyst banner through the first warning/error.
- `config.yml` sections relevant to the issue.
- Whether the server is standalone, Velocity, BungeeCord, or Redis-backed.
