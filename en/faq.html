Getting started

FAQ

Short answers to the questions server owners ask before and after installing Chatalyst.

Quick answers to common questions. For problems with a clear symptom, see Common problems.

#Does it work on Spigot?

No. Chatalyst uses Paper features, so it needs Paper, Purpur or Folia. See Compatibility & conflicts.

#Which Minecraft and Java versions?

Minecraft 1.21.1 to 26.3. Use Java 21 for 1.21.1 to 1.21.11, and Java 25 for 26.1 and newer.

#Do I need PlaceholderAPI or LuckPerms?

No, both are optional. With LuckPerms, ranks and their colors appear in chat automatically. PlaceholderAPI adds %placeholders% from other plugins. The default format uses %luckperms_prefix%; without PlaceholderAPI, swap it for {player_prefix}.

#Can I keep my current chat plugin?

Use only one plugin that formats chat, or they will fight over each message. Moderation and other plugins are fine. See Compatibility & conflicts.

#Does it replace EssentialsX?

No. It works next to EssentialsX. Chatalyst loads first and takes the chat commands it provides (/msg, /nick, /me...); EssentialsX keeps everything else. Mail lives at /inbox so it never clashes with Essentials' /mail.

#Why are so many features off?

On purpose. A new install only turns on the chat and its protections, so your server runs only what you use. /cht features lists the extras and how to turn each one on. See Turn on extras.

#Is it in my language?

Every message is translated to each player's Minecraft language when a language file exists. English and Spanish are included; you can add more. See Languages & messages.

#Do Bedrock players (Geyser) see it correctly?

Yes. Menus have no filler items, which keeps them clean on touch screens, and animated rank tags fall back to the plain tag for Bedrock players.

#Does it work on a network?

Yes. Chat channels, staff tools, mail and moderation can be shared across servers through Velocity or BungeeCord, Redis and MySQL. See Proxy & Redis networks.

#Will it slow my server down?

Chatalyst does its work off the main thread wherever it can and only runs the features you turn on. /cht perf shows a live snapshot. See Performance.

#Does it send data anywhere?

Bought on BuiltByBit: nothing; the only connection is the license check with BuiltByBit. With a key issued by the author: a license notice with the key id, server address, versions and similar server details, never players, chat or files. See License & activation and Privacy.

#Is Kagi the same as the Discord bot in Chatalyst?

No. The bot in Chatalyst is one you create for your own community. See Discord bot. Kagi is the support bot of the Kazuo Community Discord: it handles tickets and author-issued licenses, is not part of the plugin and never connects to your server.

#Where do I get help?

On the Discord community: https://discord.gg/uWTNeBmMT3.
