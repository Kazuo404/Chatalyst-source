Reference

Variables

Write a piece of text once and reuse it in any format or message as {name}. Optional JavaScript variables add simple logic.

Variables are pieces of text you write once and reuse anywhere as {name}. Put your server name, Discord link or a styled tag in a variable, use it in your formats and messages, and change it later in one place.

Plain text variables work straight away. Script variables (with js:) need scripting turned on.

#Create a variable

Variables live in plugins/Chatalyst/integrations.yml. This is the shipped example:

yaml
Variables:
  server_name: "<gradient:#240046:#9D4EDD:#E0AAFF>YourServer</gradient>"
  discord_link: "discord.gg/example"
  # SCRIPT variables (JavaScript). Start the value with "js:". You get 'player'
  # (the player) and 'playerName'. Examples:
  #   {vip_tag}  ->  shows [VIP] only if the player has the permission.
  vip_tag: "js: player.hasPermission('chatalyst.vip') ? '<#D8B4FE>[VIP] ' : ''"
  #   {name_len} ->  the length of the player's name.
  name_len: "js: player.getName().length()"

Change the values, or add your own lines with any name. Run /cht reload.

#Use a variable

Write the name in braces anywhere Chatalyst shows text: chat formats, join messages, announcements and custom commands. For example, the /discord custom command can use the link from the variable, so you only keep it in one place:

yaml
    Messages:
      - "<#5865F2>Our Discord: <#FBF2FF><underlined>{discord_link}"

#Script variables

A value that starts with js: is a small JavaScript expression. It can show different text for different players, for example a [VIP] tag only for players with a permission.

Scripts are off by default. Turn them on in the same file:

yaml
Scripting:
  Enabled: true

Inside a script you have player (the player) and playerName (their name). Scripts run in a safe engine where dangerous classes are blocked, and they are compiled once and cached.

Tip

Keep scripts short: they can run for every message. For a simple tag based on a permission, a format part with Sender_Permission is faster and needs no scripting. See Chat formats.

#Variables and placeholders

Variables are your own text. Placeholders are values Chatalyst fills in for you, such as {player_name} or {ping}. Both use the same {name} style; see Placeholders for the built-in ones.
