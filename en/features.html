Getting started

Turn on extras

Chatalyst ships with only the chat on. Use /cht features to see every optional feature and switch on the ones you want.

Chatalyst is a chat plugin first. A new install turns on the chat and its protections, and leaves every other feature off. That way your server only runs what you actually use, and nothing surprises your players.

This page shows how to see what is on, and how to switch an extra on in two steps.

#See what is on

Run this in game or in the console:

text
/cht features

It prints two lists. On shows what is running. Off shows each disabled feature with the exact setting and file to change, for example Mail.Enabled: true (players.yml). It needs chatalyst.admin.

#Turn an extra on

  1. Open the file named in the list, inside plugins/Chatalyst/.
  2. Find the setting and change false to true. For example, to turn on mail in players.yml:
yaml
Mail:
  Enabled: true
  1. Save and run /cht reload. A few features need a full restart; /cht features says so when it applies.

To turn something off again, set it back to false and reload.

Note

Updating Chatalyst never changes these switches on a server that is already installed. What you turned on stays on, and what you left off stays off.
