Moderation

Spy & logs

Let trusted staff watch private messages, commands, signs and more, and review what was said or done later from daily logs.

Spy mode lets trusted staff see what happens outside public chat: private messages, signs, books, anvil renames, chests opened and fights started. Logs keep a daily record of chat and these events, so staff can check what happened after a complaint, even when nobody was watching.

The chat log is on by default. Spy is available to operators straight away.

#Spy mode

text
/spy

With no arguments it opens a menu with the main switch and each spy type, showing which types your rank can see. /spy toggle switches it on or off, and /spy <player> watches only that player. The watched player is never told.

Permission Sees
chatalyst.spy Everything below, and can use /spy.
chatalyst.spy.pm Private messages only.
chatalyst.spy.command Commands only.
chatalyst.spy.sign Signs only.
chatalyst.spy.book Books only.
chatalyst.spy.anvil Anvil renames only.
chatalyst.spy.container Chests, barrels and mechanisms used, with coordinates.
chatalyst.spy.combat A line when a fight starts and when someone is killed.
chatalyst.spy.channel Party channel messages.

Give each staff rank only the types it needs. chatalyst.spy.autoenable turns spy on when they join.

#What spy covers

Each type can be turned off in players.yml under Spy. Command spy ships off, because a login plugin with an unusual command could expose passwords:

yaml
  Commands:
    # Disabled by default: command spy can expose credentials if a third-party
    # auth plugin uses an unknown command. Enable only for trusted staff.
    Enabled: false

Login and private message commands are never spied, even if you remove them from the Ignore list.

#Chat logs

Logs are on by default and rotate into one file per day in plugins/Chatalyst/logs/. Each kind of entry has its own switch in moderation.yml:

yaml
Log:
  Enabled: true
  Chat: true
  Commands: true
  Private_Messages: true
  Mail: true
  Signs: true
  Books: true
  Anvil: true

Keep_Days: 30 deletes files older than 30 days (0 keeps them forever). Password commands such as /login are never written.

#Review history in game

Command Shows
/chatlog [player] [count] Recent chat. Give several players to rebuild just their conversation.
/containerlog [player] [count|date] Containers and mechanisms used, with buttons to teleport there.
/combatlog [player...] [count|date] Who started each fight and who killed whom.

/chatlog needs chatalyst.command.log.

#Staff security

Staff security records when staff use sensitive commands (bans, mutes, spy, vanish...) to the console and, with the Discord bot, to a private staff channel. It blocks nothing; it leaves a clear trail. Turn it on in moderation.yml with Staff_Security.Enabled: true.
