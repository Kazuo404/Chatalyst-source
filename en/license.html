License & activation

How your license works when you buy on BuiltByBit, what the check sends, what happens without internet, and how author-issued keys work.

Chatalyst is a paid plugin by DevKazuo. This page explains how the license works, what it sends and what happens if something fails, so there are no surprises.

#Bought on BuiltByBit

Your purchase is the license. There is no key to paste: download Chatalyst from BuiltByBit, put it in plugins/ and start the server. Leave License.Key empty in config.yml.

  • The license is checked once, when the server starts, with BuiltByBit's official API.
  • If BuiltByBit cannot be reached, Chatalyst keeps starting for up to 14 days with the last answer BuiltByBit signed. A BuiltByBit outage never takes your server down.
  • The very first start needs internet, so Chatalyst can get that first answer.
  • Chatalyst never turns itself off while the server is running.
  • Nothing is sent to the author. The only connection is the check with BuiltByBit. See Privacy.

One purchase covers every server you run, including test servers. See what counts as your network.

Note

Always download the jar from your BuiltByBit purchases. Each download is marked for your account; a copy downloaded by someone else, or a modified jar, does not start.

#What counts as your network

A license belongs to one owner: a person, or a team or company that runs the servers together. One purchase covers every server that owner runs:

  • every production server, such as lobbies, survival and minigames, on any host and with or without a proxy;
  • test, staging and development servers;
  • servers you move or rebuild.

Each of these needs its own purchase:

  • a server run by a different owner, even a friend, partner or client;
  • a host or setup service that installs Chatalyst for its customers;
  • a network that changes owner: the new owner buys their own license.

A developer or admin you hire may install Chatalyst on your servers. It stays your license. Sharing a license between owners breaks these terms and can end the license and support.

#Keys issued by the author

Some licenses are given directly by the author (for example, giveaways or partners). Those come as a personal key from a Discord ticket (https://discord.gg/uWTNeBmMT3). Put it in plugins/Chatalyst/config.yml and restart:

yaml
License:
  Key: ""

The same key works on every server you own. The key itself is checked offline. With a key, Chatalyst also tells the author that the license is in use, on startup and once a day. That notice contains:

  • the key id and a random install id;
  • the server's IP and port, plus the approximate location and network provider that come from that IP;
  • server, plugin and Java versions, operating system, CPU cores and memory limit;
  • online mode, player count and MOTD.

Nothing about your players, their chat or your files is sent. See Privacy for how long this is kept. Every 6 hours Chatalyst checks whether the key has been revoked (for example, a leaked key). A short outage is fine: the last good check stays valid for 7 days. If there is no valid check for 7 days, or the key has been revoked, the plugin turns itself off and says so in the console.

#Terms in short

  • One purchase covers the servers of one owner. See what counts as your network.
  • Do not share, resell or upload the jar or its key.
  • Support is given to verified buyers on Discord. When you ask for help, include your server software, Minecraft version and the full Chatalyst startup log.
