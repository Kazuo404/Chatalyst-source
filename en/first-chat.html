Getting started

Your first chat

A step-by-step guide to change how your chat looks, from the separator to the hover, with copy-ready examples.

This guide walks you through your first change to the chat. You will edit one file, reload, and see the result in game. No previous experience is needed.

#How a chat line is built

A chat line is made of small pieces called parts, shown in order. The default format has these parts:

Part What it shows
delete A small [x] only staff see, to delete the message.
prefix The player's rank tag, for example [VIP].
party The party name, only if the player is in a party.
player-name The player's name (or nickname), with the hover card.
suffix The rank suffix, if any.
separator The » between the name and the message.
message What the player typed.

All of them live in one file: plugins/Chatalyst/formats/chat.yml.

#Step 1: change the separator

Open plugins/Chatalyst/formats/chat.yml and find the separator part:

yaml
  separator:
    Message: " <#7B68A0>» <reset>"

Change the » to a colon:

yaml
  separator:
    Message: "<#7B68A0>: <reset>"

Text uses MiniMessage: <#7B68A0> is a color, <bold> makes text bold, <reset> clears the style. Old & codes like &7 also work.

#Step 2: reload and look

Save the file and run in game or in the console:

text
/cht reload

Write something in chat. The new separator appears straight away. If something looks wrong, run /cht doctor to find the mistake.

#Step 3: color the message

The message part decides the color of what players type. By default it uses the rank color:

yaml
  message:
    Message: "{rank_color}{message}"

To make every message white, write the color yourself:

yaml
  message:
    Message: "<white>{message}"

{message} is a placeholder: Chatalyst replaces it with the real text. Placeholders lists all of them.

#Step 4: edit the hover card

Hovering a name shows a card with rank, party, money, time played and ping. It is the Hover list of the player-name part. Each line of the list is one line of the card:

yaml
    Hover:
      - " {rank_color}✦ <bold>{rank_nick}</bold>"
      - " {rank_gradient}<strikethrough>                        </strikethrough></gradient>"
      - " "
      - " <#C0B3D9>{$rank} <#7B68A0>» {player_prefix}<reset>"
      - " <#C0B3D9>{$party} <#7B68A0>» <#FBF2FF>{party}"
      - " <#C0B3D9>{$money} <#7B68A0>» <#3DFFA8>{balance}"
      - " <#C0B3D9>{$playtime} <#7B68A0>» <#FBF2FF>{playtime}"
      - " <#C0B3D9>{$ping} <#7B68A0>» {ping_ms} <#7B68A0>· {ping_quality}"

Delete a line you do not want, or add your own. Lines with {party} or {balance} hide themselves when there is nothing to show (no party, or no economy plugin). {$rank} and the other {$...} labels are translated to each player's language.

#Step 5: use the in-game editor (optional)

Prefer not to edit files? Run:

text
/formatedit chat

It opens a menu where you can change each part and save. It needs chatalyst.command.editor.

#Step 6: a different format per rank (optional)

You can give a rank its own format. Copy formats/chat.yml to, for example, formats/vip.yml, change it, and point the rank to it in plugins/Chatalyst/config.yml:

yaml
Groups:
  Enabled: true
  List: {}

Replace List: {} with an entry keyed by the LuckPerms group, where Format is the file name without .yml. The full explanation is in Chat formats.
