Performance

How Chatalyst keeps your server fast, how to check its cost live with /cht perf, and the settings that matter on big servers.

Chatalyst is built to stay off your server's main thread and to run only the features you turn on. Most servers never need to touch anything here. This page explains what it does for you and what to check if your server is large.

#Check it live

text
/cht perf

Shows a live snapshot of what Chatalyst is doing and how much it costs. It needs chatalyst.admin. If one of your rules has a slow regular expression, the snapshot warns you.

#What Chatalyst does for you
Built once per message Each chat line is built a single time, then only the small per-player parts (permissions, mentions, language) are adjusted.
Saved in the background Player data is kept in memory and written to disk or the database in batches, outside the main thread.
Off until you need it Every extra ships off, so nothing runs that you did not choose.
Cached lookups Regions, parties and ranks are cached so the chat never waits for another plugin.
Folia ready Work is scheduled per region, so it scales on Folia.

#Settings that matter on big servers

Setting File Advice
Unused extras various Leave off what you do not use. /cht features shows what is on.
Spy.Commands.Enabled players.yml Off by default. Command spy runs on every command.
Log.Keep_Days moderation.yml Default 30. Fewer days means a smaller logs folder.
Scripting.Enabled integrations.yml Off by default. Keep js: variables short if you use them.
Regex rules rules.yml Simple patterns are fast. /cht perf warns about slow ones.
Tab_Interval_Ticks nametag.yml Animated tab names resend to everyone; raise it on large networks (minimum 6).
Shared_Refresh_Seconds config.yml Default 30. Only a safety net for shared databases; changes already arrive at once through the proxy or Redis.

#Measured results

A load test on Folia 1.21.11 build 14, on 2026-10-31, with 40 simulated players in one region. They walked, chatted about 5 messages per second in total and used /msg, /r, /ch list and /ignore for 4 minutes. The server ran on Windows on one desktop PC, which also ran the bots, with Java 25 and 3 GB of memory.

Setup Lowest region TPS Average region use Disconnects Errors
Without Chatalyst 19.99 12.2% 0 0
Chatalyst with 45 of 55 features on 19.99 18.4% 0 0
Chatalyst with fewer extras on 20.00 22.6% 0 0

TPS stayed at 20 in every run. The region use figures come from short runs and vary from run to run: the setup with fewer extras scored higher than the one with more, so read them as a rough range, not an exact cost per feature. This test used simulated players, not a live community.

#On a network

With a shared MySQL, use the proxy bridge or Redis so changes reach other servers at once, and leave Shared_Refresh_Seconds at its default. See Storage & database and Proxy & Redis networks.
