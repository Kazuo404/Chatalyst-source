Optional extras

Custom commands

Create your own simple commands like /discord or /website that show a message or run console commands, without any coding.

Custom commands are small commands you create yourself, such as /discord, /website or /vote. Each one can show a few lines of text and run console commands. You write them in a config file; no coding is needed.

They are ready to use: the default file already includes /discord and /web as examples.

#Create a command

Open plugins/Chatalyst/integrations.yml and find Command_Aliases. This is the shipped example:

yaml
Command_Aliases:
  discord:
    Aliases: [dc]
    Permission: ""
    # Messages = default (English). Messages_es = Spanish clients (optional).
    Messages:
      - "<#5865F2>Our Discord: <#FBF2FF><underlined>https://discord.gg/example"
    Messages_es:
      - "<#5865F2>Nuestro Discord: <#FBF2FF><underlined>https://discord.gg/example"
    Commands: []
  web:
    Aliases: [website, pagina]
    Messages:
      - "<#3DFFA8>Our website: <#FBF2FF><underlined>https://example.com"
    Messages_es:
      - "<#3DFFA8>Nuestra web: <#FBF2FF><underlined>https://example.com"

Change the links to yours, or copy a block to make a new command. The name of the block (discord, web) is the command.

Save and run /cht reload: new, changed and removed commands apply straight away, tab completion included.

#Options

Option What it does
Aliases Other names for the same command, for example [dc] makes /dc work too.
Permission Permission needed to use it. Empty means everyone.
Messages Lines shown to the player. MiniMessage colors and links work.
Messages_es Optional Spanish lines, shown to players whose game is in Spanish.
Commands Console commands to run when the player uses it.

#Example: a vote command that gives a reward

yaml
  vote:
    Aliases: [votar]
    Permission: ""
    Messages:
      - "<gold>Vote for us at https://example.com/vote"
    Commands:
      - "give {player_name} minecraft:emerald 1"

{player_name} is replaced with the player who used the command. See Placeholders for more.

Warning

Commands run from the console every time the command is used. A reward like the one above can be repeated as often as the player wants, so only give rewards that are safe to repeat, or give the command a Permission.

Tip

To change what the player sees when they type a command that does not exist, use Unknown_Command in chat.yml.
