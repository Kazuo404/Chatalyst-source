Join, quit & death messages

Replace the plain vanilla join, quit and death lines with styled ones, greet players with a MOTD, and give high ranks a fancy entrance.

These are the lines everyone sees when a player joins, leaves or dies, plus the welcome message a player gets when they join. Chatalyst replaces the plain vanilla lines with styled ones in each player's language, and can give important ranks a little show when they arrive.

Join, quit and death messages and the MOTD are on by default. Kick messages, fancy entrances and death effects are off. Everything is in plugins/Chatalyst/messages.yml.

#Join and quit lines

yaml
Join:
  # Master switch for this backend. false hides vanilla, normal and fancy join output.
  Enabled: true
  # true = each online player sees the join line in their own client language.
  # false = use Message exactly as written for everyone.
  Use_Player_Language: true
  Message: "<#7B68A0>[<#3DFFA8>+<#7B68A0>] <#FBF2FF>{player_name} <#C0B3D9>joined"
  # Sound played to the joining player. Leave empty for none.
  Sound: "minecraft:entity.player.levelup"

Quit works the same way. A few things to know:

  • With Use_Player_Language: true (the default), the text comes from the language files, so each player reads it in their own language. Set it to false to use your Message exactly as written.
  • Enabled: false hides the line completely, vanilla included.
  • Vanished staff are never announced.
  • Players can hide these lines for themselves with /toggle joinquit.

#Different lines for different players

Add Groups to give some players their own lines. The first group whose conditions match wins, and one of its messages is picked at random:

yaml
  Groups:
    vips:
      Require_Permission: chatalyst.vip
      Messages:
        - "<#FBF2FF>{player_name} <#C0B3D9>has arrived!"
        - "<#C0B3D9>Make way for <#FBF2FF>{player_name}<#C0B3D9>!"

A group can require a permission (Require_Permission), a list of worlds (Require_Worlds) and, for deaths, a killer (Require_Killer_Contains).

#Fancy entrances

A fancy entrance is a small show when a high-rank player joins: a sound everyone hears, a harmless lightning flash, a broadcast line and a title on screen. Turn it on in messages.yml:

yaml
  Fancy:
    Enabled: false
    # true = ranked players see ONLY the fancy line (no duplicated normal join line).
    Replace_Normal_Message: true

The shipped tiers are owner, admin and vip, matched by LuckPerms group or by the permissions chatalyst.fancyjoin.owner, chatalyst.fancyjoin.admin and chatalyst.fancyjoin.vip. With Auto_Detect_LuckPerms, every other LuckPerms group gets a simple entrance automatically. You can also edit the tiers in game from /cht gui, with a preview.

#Death messages

Chatalyst replaces the vanilla death lines. It picks the first match in this order: a player killed with a named item (the item shows with its tooltip), a matching group, the line for the death cause, and finally the generic Message.

yaml
  Causes:
    PVP: "<#FBF2FF>{player_name} <#C0B3D9>was eliminated by <#FF4D6D>{killer}"
    MOB: "<#FBF2FF>{player_name} <#C0B3D9>was killed by a <#FBF2FF>{killer}"
    FALL: "<#FBF2FF>{player_name} <#C0B3D9>fell from a high place"

{killer} is the killer's own name when it has one, so a named boss is announced as itself. Set Death.Enabled: false to keep the vanilla messages. Death.Effects (off) adds a title and a sound for the killer and the victim in player fights.

#Welcome message (MOTD)

When a player joins, they get a short welcome in chat, with a different one the very first time:

yaml
Motd:
  Enabled: true
  # true = use lang/<locale>.yml -> server-messages.motd.* for each player's client language.
  # false = use the fallback lines below exactly as written.
  Use_Player_Language: true

With Use_Player_Language: true the text comes from the language files; set it to false to use the First_Time and Default lines in messages.yml. Players can read it again with /motd.

#Kick messages

Kick.Enabled: true broadcasts a line when a player is kicked, instead of the normal quit line. It ships off.

Tip

For a big welcome to players who join for the very first time, with commands such as a starter kit, see Newcomers.
