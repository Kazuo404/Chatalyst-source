Privacy

What Chatalyst sends outside your server, who receives it, how long it is kept and how to ask for it to be deleted.

This page covers the data that reaches the author or BuiltByBit because of your license. It does not cover what your own server stores about your players. That data stays on your server and you decide what to keep. See Spy & logs and Storage & database.

#Who is responsible

Chatalyst is made by DevKazuo. For any privacy question or request, open a ticket on the Kazuo Community Discord.

#Bought on BuiltByBit

Nothing is sent to the author. Your server contacts only BuiltByBit:

  • License check: once at startup, with the resource id and your BuiltByBit member id.
  • Update check: at startup, if Updates.Check is true. It asks BuiltByBit for the latest version, or your own address if you set Updates.Url. Set Updates.Check to false in config.yml to turn it off.

BuiltByBit handles these requests under its own privacy policy. Chatalyst keeps the last signed answer on your server so it can start during a BuiltByBit outage.

#Keys issued by the author

If you use a key from the author, the plugin contacts the author's license service on startup, every 6 hours and once a day. This service runs on Cloudflare and posts notices to a private Discord channel.

Data Why
Key id, buyer name and Discord id from the key Tell which license is in use
Random install id Tell installs apart
Server IP and port, plus the approximate location (city, region, country) and network provider that Cloudflare derives from that IP Detect a shared or leaked key
Server, plugin and Java versions, operating system, CPU cores and memory limit Support, and identify the copy
Online mode, player count, player limit and MOTD Tell servers apart

Player names, player IPs, chat messages and your server files are never sent.

#How long it is kept

Where What Kept for
License service Install records for a key Removed 30 days after an install was last seen, 50 installs per key at most
License service Key record (buyer, key id, issue date, Discord id) While the key exists
License service Hourly notice counters 2 hours
Private Discord channel Install, startup and activity notices Deleted automatically after 30 days
Private Discord channel Alerts about revoked keys, shared keys and modified jars Deleted automatically after 1 year
Private Discord channel Records of issued licenses While the license exists
Support Ticket transcripts in a private staff channel Deleted automatically after 1 year

#Modified jars

If the integrity check fails, Chatalyst tries once to notify the license service before refusing to start. The notice is kept only when License.Key holds a valid key. It contains the same server details listed above. Without a valid key it is discarded.

#Your options

Use a BuiltByBit copy if you want no contact with the author. To see or delete what is stored about your key or your tickets, open a ticket. We may keep what is needed to tell whether a key was revoked or to handle a dispute.

Using Discord, BuiltByBit or Cloudflare is also subject to their own privacy policies.
